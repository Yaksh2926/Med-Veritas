# Med-Veritas

AI-powered medicine authenticity verifier and prescription reader using Gemini Vision.

## Run locally

Prerequisites: Node.js

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and add your own `GEMINI_API_KEY`.
3. Start the development server with `npm run dev`.

Never commit `.env.local` or any API keys. This repository copy excludes the source repository's local environment file.
